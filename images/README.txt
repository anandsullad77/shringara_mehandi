SHRINGARA MEHANDI — GALLERY IMAGES
===================================

Put your mehandi photos in THIS folder, named exactly:

    1.jpg   2.jpg   3.jpg   4.jpg   5.jpg   6.jpg

They will appear in the website gallery automatically (no code changes needed).

Tips:
- Portrait photos look best (the tiles are tall, 4:5 ratio).
- .jpg works out of the box. If you want to use .png, tell me and I'll switch it.
- If a number is missing, that tile just shows the coloured placeholder — no error.

To download from your Instagram (@shringar_mehendi):
- Open a post on instagram.com, click the "..." menu, or take a screenshot,
  then save/rename the file into this folder as 1.jpg, 2.jpg, etc.
